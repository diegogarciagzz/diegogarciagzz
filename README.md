## ⚽ PULSE AI – Fact-Checked Football Broadcast Intelligence

**Python · FastAPI · React · TypeScript · Microsoft Foundry · Microsoft Agent Framework · Azure Container Apps · GitHub Actions**

Built solo for the **Microsoft x Premier League "Inside the Game" Developer Hackathon 2026**.

AI commentary can sound confident while getting the numbers wrong, and a broadcaster cannot put a sentence on air without knowing it is true. PULSE AI takes a synthetic football event stream and turns it into **broadcast-ready, fact-checked stories**: every AI sentence is verified against the data before it reaches the screen.

### Key Features

* 📈 **Match Pulse**, a momentum index computed from every pass, shot and recovery, with detectors for swings, pressure spells, surges and defensive stands
* 🛡️ **Narrative VAR**: claim extraction and in-code verification of every LLM sentence (VERIFIED, CORRECTED with a rewrite, UNSUPPORTED, CONFLICTED, UNVERIFIED) with an audit trail
* 🎙️ **Three-agent pundit studio**: the Analyst, the Fan and the Tactician argue Player of the Match in two bounded rounds; a moderator gives an evidence-based verdict
* 📺 **Broadcast view** with live overlays, a pitch telestrator and an auto director; a director desk can fact-check a typed commentary line on air
* 🌎 Recaps in Fan or Analyst mode, in English or Spanish
* 🧪 60 backend tests, a 69-case verification evaluation set and Playwright end-to-end tests
* ☁️ Deployed to Azure Container Apps during the hackathon with managed identity, rate limits and a daily model-call budget

### Architecture

```text
Seeded Match Simulator (1,400 events per match)
      ↓
Analytics: statistics, Match Pulse, moment detectors
      ↓
Microsoft Foundry (gpt-5-mini) writes insights from an evidence pack
      ↓
Narrative VAR verifies every claim in code
      ↓
Broadcast overlays · Agent Framework pundit debate · Recaps
```

**Backend:** Python, FastAPI, azure-ai-projects, Microsoft Agent Framework
**Frontend:** React 19, Vite, TypeScript, original brand system and broadcast overlays
**Cloud:** Azure Container Apps, managed identity, GitHub Actions, GitHub Container Registry

> All clubs, players, pundits and match data are fictional and synthetic.

## ✈️ GateGenius – AI Airline Catering Optimization

**React · Tailwind CSS · Vite · Zustand · Recharts · Gemini AI · Swift**

Built during **HackMTY 2025**, GateGenius is an AI-driven platform exploring how predictive analytics and automation can reduce waste and improve airline catering operations.

Developed during an intensive **36-hour hackathon**.

### The Challenge

Airline catering operations face significant inefficiencies caused by:

* Food expiring before being served
* Inaccurate provisioning
* Limited consumption data
* Manual workforce planning
* Poor inventory allocation

### Our Solution

GateGenius combines four intelligent systems:

#### 🥗 Expiry Tracker

Monitors perishable inventory and identifies high-risk products.

#### 🧠 AI Forecasting

Predicts passenger consumption patterns based on flight and route characteristics.

#### 👥 Shift Optimizer

Helps plan workforce requirements according to predicted demand.

#### ✈️ Smart Flight Match

Prioritizes soon-to-expire products for flights where they are most likely to be consumed.

We also developed a **native Swift iOS interface** for operational staff to scan products, inspect assignments and monitor inventory.

### Modeled Prototype Impact

* 📉 Up to **78% lower food waste**
* 💰 Approximately **$93,600 modeled savings per facility/year**
* 📦 Up to **45% lower over-provisioning losses**
* ⚙️ Up to **30% higher operational efficiency**

> These figures represent projected/model-based results from the prototype and not production deployment measurements.

### Tech

```text
React
Tailwind CSS
Vite
Zustand
Recharts
Gemini AI
Swift
```

## ♟️ MOVES – Accessible Voice-Controlled Chess

### *Hear the Game. Master the Mind.*

**Swift 6 · SwiftUI · Speech Recognition · AVFoundation · async/await**

An accessibility-focused chess application developed for the **Swift Student Challenge**, designed to explore how blind and visually impaired players can interact with chess through **voice rather than relying exclusively on visual board interaction**.

### How It Works

```text
Voice Input
     ↓
Speech Recognition
     ↓
Command Parser
     ↓
Chess Engine
     ↓
Move Validation
     ↓
Game State
     ↓
Audio / UI Feedback
```

Players can give spoken chess commands such as:

```text
"e2 to e4"
```

MOVES recognizes the command, extracts the chess coordinates, validates the move and updates the game.

### Key Features

* 🎤 Voice-controlled chess moves
* 🗣️ Apple Speech Recognition
* ♟️ Chess game logic and move validation
* 🤖 Opponent chess engine
* 🎚️ Difficulty selection
* 🔊 Audio feedback
* 🎙️ Microphone and speech permission management
* ⚡ Modern Swift concurrency with `async/await`
* 📱 iPhone and iPad support
* ♿ Accessibility-first interaction design

### Engineering

The voice pipeline uses modern Swift architecture including:

* Swift Observation
* `@Observable`
* `async/await`
* AVFoundation
* Speech Recognition
* Dedicated chess game logic
* Separate opponent-engine logic
